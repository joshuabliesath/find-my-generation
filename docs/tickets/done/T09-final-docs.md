# T09 — Final docs pass

**Model:** haiku
**Depends on:** all others

## Goal
Docs that are accurate and minimal. A new session should understand the project from `docs/README.md` + `docs/STATUS.md` alone.

## Read
- Everything in docs/ (not the tickets folder)
- File names in the repo (not their contents unless a doc looks wrong)

## Do
- Fix anything out of date. Remove leftover "_filled in by…_" placeholders.
- Cut repetition. Each fact should live in one file only.
- Move finished tickets to `docs/tickets/done/`.
- Add a "Next up" section to STATUS.md that lists the Future items from README.md.

## Don't
- Change code.

## Done when
- Docs are consistent with the code. Git commit made.
- HANDOFF.md says "No ticket queued."
